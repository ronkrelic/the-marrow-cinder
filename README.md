# The Marrow-Cinder

A browser-based 3D first-person action RPG set in the world of Mourne - a decaying, sunless expanse drowned in the Withering, where humanity survives huddled beneath Pyre-Spires that burn with the eternal flame of the Marrow-Cinders.

Status: concept phase. This repository holds the design bible, concept art, and (soon) the code for the playable vertical slice: Act I's opening in the settlement of Barrow's End.

Built by Relic (design, world, story) and Ember (engineering, art pipeline).
